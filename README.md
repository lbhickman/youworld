# YouWorld

**Free, open-source practice-test software for your own multiple-choice questions.**

YouWorld turns question sets you already have (a school practice exam, a PDF of review questions, or questions generated by an AI assistant from your notes) into a familiar exam-style question bank. Import a Markdown file, then build randomized blocks filtered by subject and source, answer in Tutor or Test mode, and track your performance over time.

Runs on macOS, Windows, and Linux. Your data stays on your computer.

---

## Features

- **Question banks.** Keep separate banks (for example "Step 1", "Neuro Block", "Boards Review") and choose one when the app opens.
- **Import from Markdown.** One `.md` file holds questions, answer choices, the answer key, explanations, educational objectives, tags, sources, and figures. Images can come along as separate files, a folder, or a `.zip`.
- **Safe re-importing.** Questions are recognized by their ID (or by their text), so importing the same or an expanded file again adds only the new questions and keeps all progress on the old ones.
- **Create Test.**
  - Question pools: Unused, Incorrect, Marked, Omitted, Correct (any combination).
  - Filter by subject tags and by source, with live counts.
  - Up to 100 questions per block, randomly selected.
  - **Tutor mode** (answer and explanation right after each question) or **Test mode** (review everything after ending the block).
- **Exam interface.** Numbered question list, mark/flag, previous/next, keyboard shortcuts, block timer, adjustable text size, full screen, suspend and resume, end block.
- **Lab Values panel.** Searchable reference ranges (conventional and SI units), editable to match your school's sheet.
- **Rich content.** Bold/italics, lists, tables, images, and LaTeX math (`$...$`, `$$...$$`).
- **Results and Performance.** Per-test results, overall correct/incorrect/omitted, bank usage, and breakdowns by subject tag and by source.
- **Question Library.** Search, filter, preview, and delete questions.
- **LLM Formatting Guide.** A built-in instructions file you can save as `.md` or `.txt` and give to ChatGPT, Claude, Gemini, or another AI assistant so it converts your questions into YouWorld format.
- **Backup and restore.** Export a bank with all progress to a single file and restore it on another computer.

## Getting YouWorld

### Option 1: Download a built app (easiest)

Download the latest `.dmg` (Mac), `.msi`/`.exe` (Windows), or `.AppImage`/`.deb` (Linux) from this repository's **Releases** page.

**First launch on a Mac:** YouWorld is free and is not signed with a paid Apple Developer certificate, so macOS will warn you the first time.

1. Open the `.dmg` and drag **YouWorld** into **Applications**.
2. Double-click YouWorld. When macOS says it cannot verify the developer, click **Done** (or **Cancel**).
3. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to the YouWorld message. Confirm with your password.

You only need to do this once.

### Option 2: Let GitHub build it for you (no Xcode needed)

If you put this project on GitHub, the included workflow (`.github/workflows/build.yml`) builds the Mac, Windows, and Linux apps on GitHub's servers.

1. Create a new repository on GitHub and upload this project's files.
2. Go to the **Actions** tab, choose **Build YouWorld**, and click **Run workflow**. When it finishes (about 10–15 minutes), download the app from the run's **Artifacts** section.
3. To publish a release instead, push a version tag (for example `git tag v1.0.0 && git push --tags`). A draft release with all installers appears on the **Releases** page; review it and click **Publish**.

### Option 3: Build it on your own Mac

You need [Node.js](https://nodejs.org) (version 18 or newer), [Rust](https://rustup.rs), and Apple's Command Line Tools (run `xcode-select --install` in Terminal; the full Xcode app is **not** required).

```bash
npm install
npm run tauri dev      # run the app in development mode
npm run tauri build    # build YouWorld.app and a .dmg in src-tauri/target/release/bundle/
```

## Writing questions

Each question starts with `## Question` and has `### Stem`, `### Choices`, and `### Answer` sections. Everything else is optional but recommended.

```markdown
---
Source: Block 3 Practice Exam
---

## Question
ID: renal-002
Tags: Nephrology, Physiology

### Stem
Which segment of the nephron reabsorbs the largest fraction of filtered sodium?

![Nephron diagram](images/renal-002.png)

### Choices
A. Proximal convoluted tubule
B. Thick ascending limb of the loop of Henle
C. Distal convoluted tubule
D. Collecting duct

### Answer
A

### Explanation
The **proximal convoluted tubule** reabsorbs about two thirds of filtered sodium.

### Educational Objective
Most filtered sodium is reclaimed in the proximal tubule.
```

| Part | Required | Notes |
|---|---|---|
| `## Question` | Yes | Starts each question. |
| `ID:` | Recommended | Unique and stable. Lets YouWorld recognize the question on re-import (and update its text if you fix a typo). |
| `Tags:` | Optional | Comma-separated, free-form subjects. |
| `Source:` | Optional | Where the question came from. Can be set once for a whole file in the front matter. |
| `### Stem` | Yes | Question text. |
| `### Choices` | Yes | `A. `, `B. `, … any number from 2 to 26. Single best answer. |
| `### Answer` | Yes | The letter of the correct choice. |
| `### Explanation` | Recommended | Markdown, tables, images, math. |
| `### Educational Objective` | Optional | Take-home point shown below the explanation. |

The full specification, with rules written for AI assistants, is in the app under **LLM Formatting Guide** (save it as `.md` or `.txt`). A sample bank with images is in [`sample/`](sample/).

### Converting existing questions with an AI assistant

1. In YouWorld, open **LLM Formatting Guide** and click **Save as .md**.
2. Start a chat with an AI assistant. Attach the guide plus your source questions (PDF, Word document, or pasted text) and ask: *"Convert all of these questions into YouWorld format following the attached instructions."*
3. Save the reply as `questions.md`, put any images in an `images` folder next to it, and import the file (or the folder, or a `.zip` of the folder).

Always spot-check AI-converted questions, especially answer keys.

## Where your data is stored

- **macOS:** `~/Library/Application Support/io.github.lbhickman.youworld/`
- **Windows:** `%APPDATA%\io.github.lbhickman.youworld\`
- **Linux:** `~/.local/share/io.github.lbhickman.youworld/`

Each bank is a JSON file (`bank-*.json`) with its images in `assets-*.json`. Use **Backup** on the bank selection screen to export a bank to a single portable file.

## Keyboard shortcuts (during a test)

| Key | Action |
|---|---|
| ← / → | Previous / next question |
| A, B, C… | Select an answer choice |
| Enter | Submit (Tutor mode) |
| M | Mark / unmark (when no choice uses the letter M) |

## Lab values

The built-in panel uses common adult reference ranges compiled for YouWorld. Ranges differ between laboratories and exams, so check them against the official reference used for your exam, and edit them under **Lab Values** in the main menu. The panel includes a link to the official USMLE sample materials, which contain the laboratory values provided during the exam.

## Project structure

```
src/                React + TypeScript interface
  parser.ts         Markdown question format parser
  importer.ts       File/folder/.zip import, images, de-duplication
  stats.ts          Question status, pools, scoring
  llmInstructions.ts  The LLM Formatting Guide text
  labValues.ts      Default lab reference ranges
  components/       Screens (bank picker, create test, exam, results, …)
src-tauri/          Tauri (Rust) desktop shell and local file storage
sample/             Example question bank with images
.github/workflows/  Automatic builds for macOS, Windows, Linux
```
